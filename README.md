# 🔮 Угадайка — инструкция по размещению на GitHub Pages

## Шаг 1: Создайте репозиторий

1. Зайдите на **github.com** и нажмите **«New repository»**
2. Назовите репозиторий строго: `<ваш_логин>.github.io`  
   Пример: если логин `ivanov` → репозиторий `ivanov.github.io`
3. Выберите **«Public»** → нажмите **«Create repository»**

## Шаг 2: Загрузите файл

1. Откройте репозиторий
2. Нажмите **«Add file → Upload files»**
3. Перетащите `index.html` и нажмите **«Commit changes»**

## Шаг 3: Включите GitHub Pages

1. Перейдите в **Settings → Pages**
2. Source: Branch `main`, Folder `/ (root)`
3. Нажмите **«Save»**

Через 1–2 минуты сайт будет на: `https://<ваш_логин>.github.io`

---

## Как пользоваться

**Персонажи** — добавьте имя, эмодзи, описание и теги  
**Вопросы** — напишите вопрос и отметьте персонажей, кто отвечает «Да»  
**Игра** — акинатор выбирает лучший вопрос автоматически, сужая список

Данные сохраняются в localStorage браузера.
